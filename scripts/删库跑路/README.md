# 《删库跑路》剧本说明

## 剧情一句话
实习生手滑删了生产库，主管选择捂盖子对外谎称系统维护，最终CTO发现真相，选择如实面对。

## 风格
有紧张感和情绪反转，结局相对正向，比另外两个剧本更有戏剧节奏。

- 主场景：会议室/教室（大部分戏在这里）
- 可选加一个"电脑前"场景（两人对话）
- 建议演实习生小李的人提前熟悉台词，戏份最重
