# 《用户协议》剧本说明

## 剧情一句话
App违规收集用户数据一年，公司的解决方案是把条款加到协议第47页字号8号三秒弹窗自动消失，直到一个真的读了协议的用户把这件事发上了热搜。

## 风格
荒诞喜剧，讽刺感最强，结尾留白最有深度，适合演技发挥空间大的组合。

## 拍摄设置
- 主场景：会议室（公司内部戏）
- 用户场景：随便找个地方，两个人各拿手机演即可
- 旁白台词有趣，适合找有表现力的人来演
