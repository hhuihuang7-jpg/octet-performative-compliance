# 《上线！》剧本说明

## 剧情一句话
AI简历筛选系统上线前，所有人走了一遍伦理审查流程、所有人签字合规，出了歧视丑闻后所有人甩锅，然后整改三天，再次上线。

## 风格
讽刺喜剧，结尾循环，台词少，好演。

## 拍摄设置
- 单机位，对着会议桌（教室拼几张桌子）
- 第一幕和第三幕同一个场景，体现循环
- 全程一个下午可拍完
